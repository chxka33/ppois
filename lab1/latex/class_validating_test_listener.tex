\doxysubsection{Detailed Description}
Event listener that internally counts and validates received events.

Currently only performs validation by counting received events, rather than performing full matching. This means that it won\textquotesingle{}t fail if the \texorpdfstring{$\ast$}{*}\+Ended events are provided in wrong order, as long as they come in the right amount and with the right nesting.
