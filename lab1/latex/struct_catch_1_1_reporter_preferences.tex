\doxysubsection{Detailed Description}
By setting up its preferences, a reporter can modify Catch2\textquotesingle{}s behaviour in some regards, e.\+g. it can request Catch2 to capture writes to stdout/\+stderr during test execution, and pass them to the reporter.
