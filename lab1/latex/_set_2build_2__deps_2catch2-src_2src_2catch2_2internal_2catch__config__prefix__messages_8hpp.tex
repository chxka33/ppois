\doxysubsection{Detailed Description}
Wrapper for the CATCH\+\_\+\+CONFIG\+\_\+\+PREFIX\+\_\+\+MESSAGES configuration option

CATCH\+\_\+\+CONFIG\+\_\+\+PREFIX\+\_\+\+ALL can be used to avoid clashes with other macros by prepending CATCH\_. This may not be desirable if the only clashes are with logger macros such as INFO and WARN. In this cases CATCH\+\_\+\+CONFIG\+\_\+\+PREFIX\+\_\+\+MESSAGES can be used to only prefix a small subset of relevant macros.
