\doxysubsection{Detailed Description}
\subsubsection*{template$<$typename Integer\+Type$>$\newline
class Catch::\+uniform\+\_\+integer\+\_\+distribution$<$ Integer\+Type $>$}
Implementation of uniform distribution on integers.

Unlike {\ttfamily std::\+uniform\+\_\+int\+\_\+distribution}, this implementation supports various 1 byte integral types, including bool (but you should not actually use it for bools).

The underlying algorithm is based on the one described in "{}\+Fast Random \+Integer Generation in an Interval"{} by Daniel Lemire, but has been optimized under the assumption of reuse of the same distribution object.
